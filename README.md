# Scan-chan

Android向けのバーコード入力キーボードです。配送用のEAN-13をカメラで読み取り、Ytrackの番号欄へ入れます。日本語や英語を入力するときは、いつものキーボードを使います。このリポジトリではAPKと利用案内を配布しています。

[0.8.9のAPKをダウンロード](https://github.com/totkd/Scan-chan-releases/releases/download/v0.8.9/Scan-chan.apk) · [変更内容・過去のバージョン](https://github.com/totkd/Scan-chan-releases/releases)

**Android 10以上**に対応します。端末へ入れるファイルは **Scan-chan.apk** です。Chromeでこのリンクを開き、ダウンロードが終わったら「開く」を押してください。

## 0.8.9の変更

- 業務で読み取るための設定を、**「Scan-chan 業務の読み取り連携」1項目**にまとめました。自動切替も使う方だけ、もう1項目を設定します。
- 数字キーの右下に **Enter** を追加しました。入力している画面に応じて、次の欄へ進んだり入力を終えたりできます。
- スキャンボタンを使わない画面では、キーボードの高さを低くしました。ボタンを消した跡に空白が残る問題も直しました。
- **「入力を試す」** でも、バーコードを1件ずつ読んで練習できます。ここでは荷物の登録や問い合わせの送信は行いません。

一部端末で読み取れなかった問題への0.8.6の対応と、従来の連続読み取りも維持しています。

## 初回設定

詳しい操作は [写真付き・はじめての使い方（ドライバー向け）](INSTALL.md)、配布やAndroid 10の自動切替は [担当者向け設定](INSTALL_ADMIN.md) をご覧ください。

1. ChromeでAPKをダウンロードし、ダウンロード完了後の「開く」からインストールします。必要に応じて、Chromeからのアプリのインストールを許可します。
2. Scan-chanを開き、**「はじめの設定」**を1画面ずつ進めます。カメラの使用を許可してください。
3. **Android 13以降では、いつものキーボードのまま先に業務連携を設定します。** 下の制限解除が必要な場合も、Scan-chanのキーボードへ切り替える前に済ませます。
4. 続く案内で、キーボード一覧のScan-chanをONにし、入力方法にもScan-chanを選びます。古いAndroidでは、この手順が業務連携より先に出ます。画面の順番に従ってください。
5. 自動切替は使いたい方だけ設定します。使わない場合や担当者の初回設定待ちは、**「今は手動で使う」**で進めます。
6. **「設定一覧を開く」**まで進めたら完了です。以降は一覧から変更できます。設定し直すときは「使い方を見る → 最初の準備」を開きます。

> [!IMPORTANT]
> **「制限付き設定」と出てONにできないとき**
>
> まずユーザー補助の **「Scan-chan 業務の読み取り連携」** をONにしようとして、制限の警告を一度表示します。「OK」で閉じてScan-chanへ戻り、**「制限付き設定で進めないとき → アプリ一覧を開く → Scan-chan」**と進みます。Scan-chanを選んだ先のアプリ情報で **「︙ → 制限付き設定を許可」** を押し、端末の本人確認を行います。その後ユーザー補助へ戻り、業務連携をONにしてください。
>
> 先にアプリ情報を開くだけでは、︙が出ない場合があります。暗証番号を入力できるよう、許可が終わるまではいつものキーボードで進めます。暗証番号の内容を担当者へ伝える必要はありません。

**Android 10の自動切替だけは、初回に担当者のPC/Mac設定が必要です。** 通常の読み取りと業務連携、Android 11以上の自動切替は端末内で設定します。会社の管理によって設定が制限されている場合は、担当者へ確認してください。

## 読み取りと数字入力

バーコードの中心を、カメラ画面の十字に合わせてください。

- **持出・配完**：空の番号欄で連続読み取りを始めます。実際に登録します。「登録済み」は自動で閉じ、結果不明や未知のエラーでは停止します。
- **貨物問い合わせ**：空の番号欄から連続で読み、9件で停止します。最後にYtrackの「開始」を押します。
- **持ち帰り・その他業務**：Ytrackの自動登録をOFFにします。番号欄で1件読むと、番号だけが入りカメラが閉じます。その他業務は選んだ理由を問いません。必要な登録は、内容を確認してYtrackで行います。
- **「入力を試す」**：2つの練習欄で数字入力・Enter・1件ずつのスキャンを試せます。読み取ると番号が入り、カメラが閉じます。荷物登録・問い合わせ送信は行いません。
- **その他の入力欄**：数字キーとEnterを使えます。スキャンボタンは表示されません。

業務で使う読み取りは、まとめて **「Scan-chan 業務の読み取り連携」** をONにして準備します。

## キーボードを隠して一覧を見る

業務の読み取り中に端末の **「戻る」** を押すと、読み取りが止まり、キーボードが隠れます。一覧を見ている間は勝手に出てきません。番号欄を押すとキーボードだけが戻ります。読み取りは **「スキャン」** で再開します。

## すでに使っている端末を更新する

**先にScan-chanを削除する必要はありません。**

1. Scan-chanの **「使い方を見る → アプリの更新 → 更新ページを開く」** からChromeで最新版APKを取得します。
2. ダウンロード完了後の「開く」から **「更新」** を押します。従来と同じ配布署名で、設定を引き継げます。
3. 更新後は設定一覧の **「業務での読み取り」** が使える状態か確認します。未設定なら「Scan-chan 業務の読み取り連携」をONにしてください。
4. 自動切替を使っている場合は、こちらも使える状態か確認します。

以前の「貨物問い合わせ」がONだった端末では、設定を引き継げる場合があります。**旧「貨物問い合わせ」がOFFだった端末は、新しい業務連携をONにしてください。** 古い業務別の設定は、新しい1項目へまとめています。

以前の試験版は配布版と署名が異なるため、初回だけ担当者による移行が必要な場合があります。通常の更新中に削除を求められたら、担当者に確認してください。アンインストールすると設定・権限が消え、設定し直しが必要になります。自動で更新を確認したり、インストールしたりする機能はありません。

## 音・振動とデータ

読み取り音はピコン・ピロリン・キラッ・ポロロンなど、無音を含め8択です。エラー音はプップー・低いププッ・下がるポポッ・無音の4択です。選ぶと保存され、試しに音が鳴ります。数字キーの配置・高さも設定できます。

読み取りは端末内で処理し、広告はありません。Scan-chanはカメラ画像・スキャン番号・入力内容を保存せず、インターネット権限もありません。ダウンロード用URLは外部ブラウザで開きます。入力先アプリ側の保存・通信は、そのアプリの仕様に従います。

## 確認した範囲

A101KC / Android 13で、利用者本人による新規導入と初期設定、Enter、練習画面のスキャン、テンキーの空き領域の解消を確認しました。初期設定では操作の補足を行っており、案内だけで単独完了できたことを実証したものではありません。最終配布APKと端末内APKのSHA-256も一致しています。

Enter・練習スキャンを追加した段階で単体テストDebug 152件・Release 128件が成功しました。最終の高さ修正後は、ビルド・Release LintとAndroid 13のNativeテスト29件が成功しています。今回の新たな持出・配完の実登録、長時間運用、別機種での確認は行っていません。

ログイン画面で「戻る」を押してもキーボードが一時的に隠れないとの報告がありましたが、その後は再現せず、原因は未確定です。
