# Scan-chan

Android向けのバーコード入力キーボードです。日本語・英語には普段のキーボードを使い、Scan-chanで配送用のEAN-13を読み取ります。このリポジトリではAPKと利用案内を配布しています。

## ダウンロード

[最新版APKをダウンロード](https://github.com/totkd/Scan-chan-releases/releases/latest/download/Scan-chan.apk)

[0.8.3のAPKをダウンロード](https://github.com/totkd/Scan-chan-releases/releases/download/v0.8.3/Scan-chan.apk) · [変更内容・過去のバージョン](https://github.com/totkd/Scan-chan-releases/releases)

Android 10以上に対応します。端末へ入れるファイルは **Scan-chan.apk** です。

## 初回設定

詳しい操作は [写真付き・はじめての使い方（ドライバー向け）](INSTALL.md)、Android 10の自動切替は [担当者向け設定](INSTALL_ADMIN.md) を参照してください。

1. 端末のブラウザでAPKをダウンロードして開きます。必要に応じて、そのブラウザ等に「不明なアプリのインストール」を許可します。
2. 初回起動の **「はじめの設定」** を1画面ずつ進めます。カメラの許可、キーボードのON、入力方法のScan-chan選択は別々の画面で案内します。
3. 使う業務の画面では、Androidのユーザー補助をONにしてScan-chanへ戻り、「設定できています」から次へ進みます。使わない業務は後回しにできます。
4. 自動切替を使わない場合やAndroid 10の初回設定待ちは、**「今は手動で使う」** で完了できます。
5. 最後の「準備ができました」で **「設定一覧を開く」** を押します。以降は一覧から変更できます。設定を見直す場合は「使い方を見る → 最初の準備」を開きます。

キーボード自動切替を使う場合は、同名の設定画面の案内に従います。**Android 10の自動切替だけは初回に担当者のPC/Mac設定が必要です。** Android 11以上は端末内で設定する実装です。通常の読み取りと業務連携は端末内で設定できます。会社管理端末では管理者による利用制限がある場合があります。

## 読み取り

2から始まる有効な13桁のEAN-13を読み取ります。バーコードの中心を十字に合わせてください。隣り合う番号では、中央に明らかに近い番号を選び、狙いが曖昧な間は入力を保留します。数字の手入力、左右移動、1文字削除、全削除も使えます。

- **Ytrackの持出・配完**：対象業務の空の番号欄で、スキャンボタンに業務名と「連続読み取り」が出ることを確認して開始します。実際に登録します。通常の「登録済み」は自動で閉じて継続し、結果不明や未知のエラーでは停止します。終わったら「停止」を押します。
- **Ytrackの貨物問い合わせ**：対象の空の番号欄から連続読み取りを始め、9件で停止します。最後にYtrackの「開始」を押します。
- **その他の入力欄**：通常は1件の入力成功でカメラが停止します。Enterは自動送信しません。

## 更新

Scan-chanの「アプリの更新」から外部ブラウザで最新版APKを取得し、開いて更新します。同じ配布署名版は上書き更新できます。自動の更新確認やインストールは行いません。

以前のPoC版は配布版と署名が異なるため、初回だけ担当者による移行が必要な場合があります。通常の更新中に削除を求められた場合は、担当者に確認してください。**アンインストールすると設定・権限が消え、キーボードとユーザー補助、Android 10の自動切替の初回権限も再設定が必要です。**

## 音・振動とデータ

読み取り音は既存3種にピコン・ピロリン・キラッ・ポロロンを追加し、無音を含め8択。エラー音はプップー・低いププッ・下がるポポッ・無音の4択です。選ぶと保存され、試しに音が鳴ります。テンキーの配置・高さも設定できます。読み取りは端末内で処理し、広告はありません。アプリはカメラ画像・スキャン番号・入力内容を保存せず、インターネット権限もありません。更新用URLへのアクセスは外部ブラウザが行います。入力先アプリ側の保存・通信は、そのアプリの仕様に従います。
