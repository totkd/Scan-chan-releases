# Scan-chan

Android向けのバーコード入力キーボードです。日本語・英語は普段のキーボードを使い、Scan-chanで配送用のEAN-13を読み取って入力します。このリポジトリにはAPKと利用案内のみを置き、ソースコードは含みません。

## ダウンロード

[変更内容・過去のバージョン](https://github.com/totkd/Scan-chan-releases/releases)

## 初回設定

1. Android 10以上の端末でAPKをダウンロードして開きます。必要なら、ダウンロードに使ったブラウザ等を「不明なアプリのインストール」の許可対象にします。
2. Scan-chanを開き、カメラを許可します。
3. 「Scan-chanキーボードを有効にする」から有効化します。Androidのキーボードに関する標準警告が表示されます。
4. 入力欄を選び、入力方法をScan-chanへ切り替えます。
5. 「スキャン」を押し、バーコードを1つだけ映します。

2から始まる13桁のEAN-13（チェックデジットが正しいもの）だけを読み取って入力します。1件の入力成功でカメラは停止し、Enterは自動送信しません。数字0〜9、左右移動、1文字削除、全削除も使えます。

## 更新

Scan-chanの設定画面上部にある「最新版をダウンロード」を押し、ブラウザで取得したAPKを開いて更新してください。自動の更新確認や自動インストールは行いません。

### 以前のPoC版から移行する場合

以前USBで入れたPoC版と、このリポジトリの配布版では署名が異なります。初回だけ、通常のキーボードへ戻してPoC版をアンインストールし、配布版をインストールしてください。カメラ許可とキーボード有効化を再設定します。以後の配布版同士は上書き更新します。

## 音・振動とデータ

成功音は設定画面で「ピッ」「ピピッ」「チャイム」「無音」から選べます。対象外・未解読時は赤いフラッシュと短い振動で知らせます。

読み取りは端末内で処理し、広告はありません。アプリはカメラ画像・スキャン番号・入力内容を保存せず、インターネット権限もありません。更新用URLへのアクセスは外部ブラウザが行います。入力先アプリ側の保存・通信は、そのアプリの仕様に従います。

## ファイルの確認
